# AI 影片精華剪輯 Skill

把「剪精華短片 → 上字卡 → 上字幕」整套流程包成一個可以重複使用的 Claude Skill。只要給一支影片和一份標好重點的文字腳本，AI 就能接手大部分繁瑣的剪輯工作。

這份 Skill 原本是為「嘉義縣政府自媒體工作坊」整理的教學素材，內容已經改寫成通用版本，任何人都能直接安裝使用。

## 使用前要先準備

1. **Claude 帳號**：到 [claude.com/download](https://claude.com/download) 下載桌面版，帳號設定裡要開啟「程式碼執行」權限，Skill 才跑得動。
2. **FFmpeg**（剪輯引擎）
   - Mac：`brew install ffmpeg`
   - Windows：`winget install Gyan.FFmpeg`
3. **Whisper**（本機語音辨識）：`pip install openai-whisper`
4. **中文字型**（Mac，沒裝字幕會變成方塊）：`brew install --cask font-noto-sans-cjk-tc`

## 怎麼安裝這個 Skill

1. 點這個 repo 右上角的 **Code → Download ZIP**，下載整包檔案（不需要裝 git、不需要打指令）。
2. 打開 Claude，到 **Customize → Skills**，建立新技能，把下載下來的 zip 上傳進去。
3. 安裝完成後，開一個新對話，把你的影片和腳本準備好，就可以開始下指令。

## 怎麼下指令

不用懂程式，用中文把這四件事交代清楚就好：

1. **素材在哪**——影片、腳本分別放在哪個資料夾
2. **想要的成品**——要多長、什麼比例（例如 60 秒、直式 9:16）
3. **重點是什麼**——腳本裡有沒有先標記好要保留的重點段落
4. **要不要字卡字幕**——剪完要不要順便上字卡、燒字幕

範例：

> 「幫我剪一支 60 秒的直式短片，影片在『原始素材』資料夾裡那支，腳本是『腳本』資料夾裡的文字檔，裡面已經標好重點了。剪完之後順便上字卡和字幕。」

## 腳本怎麼標重點

在文字腳本裡用下面任一種方式標記你覺得是重點的段落，AI 會優先保留這些段落：

- `**粗體**`
- 【文字】或《文字》
- 整行用「★」「重點：」「金句：」開頭

完全沒有標記也沒關係，AI 會自己判斷金句與口播重點。

## 檔案說明

- `SKILL.md`——Skill 的完整定義與使用說明，上傳到 Claude 的就是這份檔案
- `scripts/`——SKILL.md 裡引用到的輔助程式，Skill 執行時會自動寫出來用，不需要手動執行
